Private by design

Your network snapshot
stays on your device.

NetState uses location permission only so iOS can provide the current Wi-Fi name. It does not read geographic coordinates, send SSID or IP values to the developer, run ping or speed tests, or place ads in widgets. A banner ad appears only in the main app Status screen.
